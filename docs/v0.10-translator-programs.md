# WiiCompiled Web v0.10 — Multi-instruction translated programs

## What this milestone tests

The build runs the upstream WiiCompiled translator at pinned revision
`03151e0a3429adb92dd9082fb815fbf194df3c1d` against two synthetic PowerPC
functions, then compiles the emitted C++ with Emscripten.

1. A conditional function uses `cmpwi`, `beq`, `addi`, and `blr`. The
   taken path returns 7 and the fall-through path returns 9; the browser
   calls it twice to exercise both outcomes.
2. A memory function uses `lwz`, `addi`, `stw`, and `blr`. The generated
   loads/stores call the checked browser `MemoryInline` helpers and operate on
   the sparse guest-memory adapter.

The test initializes guest memory with a known big-endian word, executes the
translated function, and verifies both the register result and stored word.

## Scope

These are synthetic instructions, not Nintendo game code or a game image.
Passing validates this small instruction subset and the helper path only. It
does not imply complete PowerPC coverage, MMIO behavior, the upstream native
memory model, or a playable game. The next stage is to expand instruction
coverage and connect more of the upstream runtime contract.
